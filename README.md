# الكارت الشخصي الرقمي (الإصدار 1.1)

صفحة كارت فيها 4 زراير: اتصال، واتساب، خريطة، إيميل.
**الشكل في `index.html` والبيانات كلها في `config.js`.** غالباً مش هتلمس `index.html` أبداً.

---

## أولاً: رفع المشروع على GitHub (مرة واحدة)

1. ادخل على github.com وسجّل دخول بحسابك.
2. اضغط **New** (أو علامة + فوق ثم **New repository**).
3. اسم الريبو: `lawyer-card` واختار **Public** ثم **Create repository**.
4. اضغط **uploading an existing file**، واسحب الملفات الثلاثة: `index.html` و `config.js` و `README.md`، ثم اضغط **Commit changes**.
5. روح **Settings** > **Pages**.
6. تحت **Branch** اختار `main` والفولدر `/ (root)` ثم **Save**.
7. استنى دقيقة أو اتنين، وهيظهر لينك الصفحة بالشكل ده:
   `https://اسم-حسابك.github.io/lawyer-card/`

---

## ثانياً: إزاي تغيّر أي بيان

1. افتح الريبو على github.com واضغط على ملف **config.js**.
2. اضغط أيقونة القلم ✏️ (Edit this file) فوق على اليمين.
3. غيّر القيمة اللي بين علامتي التنصيص `" "` في السطر المطلوب.
4. اضغط **Commit changes** الأخضر ثم **Commit changes** تاني للتأكيد.
5. استنى دقيقة أو اتنين وحدّث الصفحة (Ctrl+F5 على الكمبيوتر).

متمسحش علامات التنصيص `" "` ولا الفاصلة `,` اللي في آخر كل سطر.

### أمثلة

| عايز تغيّر | غيّر السطر |
|---|---|
| رقم التليفون | `phone` و `phoneDisplay` و `whatsapp` |
| لينك الخريطة | `mapUrl` |
| الإيميل | `email` |
| الألوان | `theme`: اكتب `"sand"` (رملي) أو `"dark"` (داكن) |
| رابط المشاركة | `shareUrl` (لينك البلوج) |

### صيغة الأرقام

- `phone`: `"+20XXXXXXXXXX"` (بـ + في الأول)
- `whatsapp`: `"20XXXXXXXXXX"` (من غير + ومن غير صفر)

### لينك الخريطة

1. افتح Google Maps وادور على مكان المكتب.
2. اضغط **Share** ثم **Copy link**.
3. الصق اللينك في `mapUrl`.

لو سيبت `mapUrl` فاضي `""` زرار الخريطة بيختفي، ولو فاضي `email` أو أي رقم الزرار المرتبط بيه بيختفي كمان.

## ملاحظات

- **الإيميل على الكمبيوتر:** الضغط على زرار الإيميل بيظهر صندوق تحته فيه الإيميل وزرار نسخ.
- **الإيميل على الموبايل:** بيفتح تطبيق الإيميل الافتراضي في الموبايل (غالباً Gmail).
- **واتساب:** الرسالة الجاهزة بتبدأ بـ "صباح الخير" أو "مساء الخير" حسب ساعة الموبايل. تقدر توقفها بـ `whatsappAutoGreeting: false`.
- بعد أي تعديل ممكن التغيير ياخد دقيقة أو اتنين عشان يظهر.
